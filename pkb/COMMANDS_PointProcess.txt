  # Query — jitter (PointProcess only)
  # ⚠️ VARIANT SELECTION IS NOT COSMETIC. Five jitter and six shimmer
  #   variants exist and are not interchangeable; `local` measures vibrato
  #   rather than stability on a modulated tone. Read APPENDIX_D §3D before
  #   emitting any of these, and emit local + rap + the ratio by default.
  #   `ddp` = 3 x `rap` and `dda` = 3 x `apq3` exactly (verified 6.6.30,
  #   and stated in the Praat manual) — redundant, never report both.
  # ⚠️ NOT COMPARABLE TO MDVP. Praat finds period boundaries by waveform
  #   matching, MDVP by peak-picking, so MDVP's jitter absorbs additive
  #   noise and Praat's does not: on a constant-period signal with 1%
  #   white noise, Praat reads 0.02% and MDVP 0.6%. Published norms are
  #   mostly MDVP-derived and applying them to a Praat value UNDER-calls
  #   pathology. See APPENDIX_D §3D and
  #   fon.hum.uva.nl/praat/manual/Voice_5__Comparison_with_other_programs.html
  Get number of periods: from time, to time, shortest period, longest period, maximum period factor
  # Verified: Get number of periods: 0, 0, 0.0001, 0.02, 1.3
  # Provenance: Sandbox-verified 6.6.30, 8 Oct 2026 (argument count from Praat's "requires only 5 arguments" error)
  Get jitter (local): from time, to time, shortest period, longest period, maximum period factor

  # Verified: Get jitter (local, absolute): 0, 0, 0.0001, 0.02, 1.3
