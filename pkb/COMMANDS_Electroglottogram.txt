  # Create (Sound command)
  Extract Electroglottogram: channel number, invert?
  # Verified: Extract Electroglottogram: 2, "no"
  # NOTE: Second argument is named "Invert". invert? = "yes" multiplies by -1
  #   (verified: -0.709517 -> +0.709517 at the same time point). Praat expects
  #   increasing value = increasing contact area. Wrong polarity doesn't
  #   error. An inverted EGG gives a dEGG CQ of 1 minus the true CQ, which
  #   usually lies inside the 0.15 - 0.85 plausibility bound, so the bound
  #   doesn't catch it (see PLAUSIBILITY BOUND below). Test polarity with
  #   the derivative peak test: BEST_PRACTICES_EGG_CONTACT_QUOTIENT.md §3,
  #   Polarity.

  # Query

  #   execution: Get start time, Get end time, Get total duration, Get number
  #   of samples, Get sampling frequency, Get time step, Get number of
  #   channels, Get value at time:, Get value at sample number:, Get minimum:,
  #   Get maximum:, Get mean:, Get time from sample number:, Get sample number
  #   from time:. Also unavailable: Formula:, Scale peak:, Extract part:,

  # Convert / Analyze
  To Sound
  # Verified: To Sound
  #   Takes no arguments.
  # NOTE: The bridge out of this type. Returns a Sound with identical
  #   duration, sampling frequency, and 1 channel. Registered without "..."
  #   — it has no dialog. Do not write a colon.

  Derivative: low-pass frequency, smoothing, new absolute peak
  # Verified: Derivative: 5000, 100, 0
  # NOTE: Returns a SOUND (suffix "_derivative"), not an Electroglottogram.
  #   Band-limited. Prefer for GCI detection on any signal that is not
  #   pristine — see BEST_PRACTICES_EGG_CONTACT_QUOTIENT.md §3.
  #   "new absolute peak" = 0.0 means do not rescale.

  First central difference: new absolute peak
  # Verified: First central difference: 0.0
  # NOTE: Returns a SOUND (suffix "_cdiff"), not an Electroglottogram.
  #   Arity is exactly 1 — the argument is a rescale factor, NOT a filter.
  #   This command applies NO band limiting whatsoever. Literature-standard
  #   differentiator; use when replicating a published dEGG protocol.

  To TextGrid (closed glottis): pitch floor, pitch ceiling, closing threshold, peak threshold
  # Verified: To TextGrid (closed glottis): 75, 600, 0.3, 0.05
  # Legacy alias: Get closed glottis intervals: (same signature, verified)
  # NOTE: Closing and opening moments are the two level crossings at
  #   valley + closingThreshold * (peak - valley), computed per cycle.
  #   Validated against an analytic reference to 3.7e-05.
  # NOTE: "peak threshold" MUST be > 0.0 despite the "(0-1)" dialog label.
  #   0.0 gives «Argument "Peak threshold" must be greater than 0.0.»
  #   It excludes cycles whose peaks fall below that fraction of the maximum.
  # *** SEGFAULT RISK — see the guard section at the end of this file. ***
  # *** BOUNDARY COLLISION — see the section at the end of this file. ***

  To AmplitudeTier (levels): pitch floor, pitch ceiling, closing threshold, peaks?, valleys?
  # Verified: To AmplitudeTier (levels): 75, 600, 0.3, "yes", "yes"
  # NOTE: Returns 1-3 objects depending on the booleans. Order is always
  #   peaks, valleys, levels:
  #     "no","no"   -> 1: <name>
  #     "yes","no"  -> 2: <name>_peaks, <name>
  #     "no","yes"  -> 2: <name>_valleys, <name>
  #     "yes","yes" -> 3: <name>_peaks, <name>_valleys, <name>
  # NOTE: Scalar assignment FAILS whenever either boolean is "yes":
  #   «Multiple objects selected. Cannot assign object IDs to numeric
  #   variable.» Use a vector: ids# = To AmplitudeTier (levels): ...
  # *** SEGFAULT RISK — see the guard section at the end of this file. ***

# ============================================================================
# TextGrid output structure (from To TextGrid (closed glottis))
# ============================================================================
#
#   Number of tiers:  1
#   Tier 1 name:      closedGlottis
#   Tier 1 type:      interval tier
#   Closed intervals: label "c"
#   Open intervals:   label ""  (empty string)
#   First interval:   always empty (domain start to first detected closure)
#
# Verified on 2.0 s / 150 Hz synthetic: 597 intervals, alternating.
#
# CQ from this TextGrid — use the closed interval plus the interval that
# immediately follows it:
#
#   for ii from 2 to nInt - 1
#       selectObject: tg
#       lab$ = Get label of interval: 1, ii
#       if lab$ = "c"
#           selectObject: tg
#           c1 = Get start time of interval: 1, ii
#           c2 = Get end time of interval: 1, ii
#           o2 = Get end time of interval: 1, ii + 1
#           if o2 - c1 > 0
#               cq = (c2 - c1) / (o2 - c1)
#           endif
#       endif
#   endfor
#
# DO NOT compute the period as closed-onset to next-closed-onset. The peak
# threshold parameter drops low-amplitude cycles, so consecutive "c" intervals
# are not guaranteed to be consecutive glottal cycles. Where a cycle has been
# dropped, an onset-to-onset period spans two cycles and CQ is silently halved.

# ============================================================================
# SEGFAULT — mandatory guard before To TextGrid (closed glottis)
#            and To AmplitudeTier (levels)
# ============================================================================
#
# Both commands CRASH PRAAT — segmentation fault, process death, session lost
# — when no glottal cycle falls inside [pitch floor, pitch ceiling]. Not a
# catchable error. No message. Praat dies.
#
# Verified crash conditions (signal F0 = 150 Hz):
#   floor 150, ceiling 600  -> works (597 intervals)
#   floor 151, ceiling 600  -> SEGFAULT
#   floor 200, ceiling 600  -> SEGFAULT
#   floor 600, ceiling 600  -> SEGFAULT   (floor >= ceiling)
#   floor 700, ceiling 600  -> SEGFAULT
# And with canonical 75, 600, 0.3, 0.05:
#   silent EGG channel      -> SEGFAULT
#   noise-only EGG channel  -> SEGFAULT
#
# The last two are the batch-processing killer: one unvoiced or silent file
# in a folder destroys the session.
#
# GUARD — validated. Blocks all five conditions; passes all valid signals
# including one at 10 dB SNR. This is a registered library procedure; its
# canonical source is eml-egg-procedures.txt (registry: EGG section). The
# copy below is illustrative — copy exactly from the source file (Retrieval Protocol step 11, RULES_RETRIEVAL.md):
#
#   procedure emlEggCycleGuard: .eggId, .floor, .ceiling
#       selectObject: .eggId
#       .snd = To Sound
#       selectObject: .snd
#       .p = noprogress To Pitch (raw cross-correlation): 0.0, .floor,
#           ... .ceiling, 15, "no", 0.03, 0.45, 0.01, 0.35, 0.14
#       selectObject: .p
#       .voiced = Count voiced frames
#       .f0 = Get mean: 0, 0, "Hertz"
#       removeObject: .p, .snd
#       .safe = 1
#       if .voiced = 0
#           .safe = 0
#       endif
#       if .safe = 1
#           if .f0 = undefined
#               .safe = 0
#           endif
#       endif
#       if .safe = 1
#           if .f0 < .floor
#               .safe = 0
#           endif
#       endif
#   endproc
#
# The nested ifs are required. Praat's "and"/"or" do not short-circuit, so a
# single compound condition would evaluate .f0 < .floor even when .f0 is
# undefined.

# ============================================================================
# BOUNDARY COLLISION — To TextGrid (closed glottis) on real signals
# ============================================================================
#
# Can fail on legitimate voiced material with:
#
#   Cannot add a boundary at 7.781719 seconds, because there is already a
#   boundary there.
#   IntervalTier "closedGlottis": boundary not inserted.
#   Electroglottogram "...": TextTier not created.
#
# Catchable, but it aborts the whole analysis for one bad cycle. Observed on
# a real 7.95 s recording at every closing threshold from 0.20 to 0.50, always
# at the same location (~7.78 s) — threshold-independent. Two glottal events
# resolving to the same boundary time.
#
# Handling: catch, trim, retry. Trimming that file to 7.80 s succeeded and
# cost 17 of 1874 cycles. Do not abandon the file on first failure.

# ============================================================================
# PLAUSIBILITY BOUND — apply to the OUTPUT, not just the input
# ============================================================================
#
# Contact quotient outside roughly 0.15 - 0.85 is not a physiological value.
# Check the result before reporting it.
#
# This single check catches, at zero cost, failures that signal-quality
# metrics do not: wrong channel, an already-differentiated signal presented
# as an EGG, and an EGG whose low-frequency content has been filtered away.
#
# It does NOT catch wrong polarity. An inverted EGG reads as 1 minus the true
# CQ, which stays inside the bound unless the true CQ is below 0.15 or above
# 0.85. Polarity is tested with the derivative peak test
# (BEST_PRACTICES_EGG_CONTACT_QUOTIENT.md §3, Polarity).
# Provenance: sandbox-verified 6.6.30, 8 Oct 2026: a synthetic EGG with a
# designed dEGG CQ of 0.425 read 0.427 upright and 0.573 inverted, with 0 of
# 592 cycles out of bounds. Worked example from verification: a differentiated signal
# analysed as an EGG returned 22.0 dB SNR ("good") and QDelta 7.73 ("strong
# contact") while producing CQ = 0.049. Only the plausibility bound caught it.
#
# Provenance: sandbox verification session, 29 July 2026. Synthetic signals
# with analytically known crossings, graded-SNR variants, and a real stereo
# audio+EGG recording.
