  # Creating a Matrix (New menu; nothing needs to be selected)

  Create simple Matrix: name$, number of rows, number of columns, formula$
  # Returns: Matrix
  # Verified: Create simple Matrix: "m", 3, 4, ~ row * 10 + col
  # Columns sit at x = 1, 2, 3 ... and rows at y = 1, 2, 3 ..., so in its
  #   formula x equals col and y equals row.
  # The formula is required. With three arguments Praat stops with "Command
  #   requires more than the given 3 arguments: argument "Formula" not given."

  Create Matrix: name$, xmin, xmax, number of columns, dx, x1, ymin, ymax, number of rows, dy, y1, formula$
  # Returns: Matrix
  # Verified: Create Matrix: "m3", 0, 1, 10, 0.1, 0.05, 1, 5, 5, 1, 1, ~ x + 100 * y
  # x1 is the x of column 1 and y1 the y of row 1. In its formula, x and y
  #   are these world coordinates, not column and row numbers.

  # Applying a formula

  Formula: formula$
  # Verified: Formula: ~ self * 2
  # Computes the expression for every cell, row by row, left to right, and
  #   writes each result into its cell before moving to the next. In the
  #   expression, self is the current cell, row and col are its numbers, x
  #   and y are its world coordinates, and nrow and ncol are the Matrix's
  #   size (APPENDIX_B_FUNCTIONS.txt).
  # The formula reads cells it has already rewritten. Formula:
  #   ~ if col > 1 then self [row, col - 1] else self fi turns a row of
  #   1 2 3 4 into 1 1 1 1. To read the original values, Copy the Matrix
  #   first and read the copy: object [copyId] [row, col - 1].
  # A cell past the edge reads as 0, with no error: self [row, col + 1] in
  #   the last column gives 0.
  # Another Matrix's cell reads as object [id] [row, col] (preferred,
  #   survives renaming), object ["Matrix m2", row, col] or Matrix_m2 [row, col].
  #   These are reads only.
  # Inside a formula, = compares. Formula: ~ self [row, col] = 2 writes 0
  #   into every cell holding 1.
  # To change part of a Matrix, test row and col:
  #   Formula: ~ if row = 2 and col <= 3 then 0 else self fi. Formula (part)
  #   does not exist for Matrix: Praat stops with "Command "Formula (part):"
  #   not available for current selection."
  # With several Matrix objects selected, the formula runs on each.
  # A result that is undefined, such as 1 / 0, is stored as undefined.

  # Linear algebra (hidden commands)
  # Eigen (complex) and To SVD are registered GuiMenu_HIDDEN in
  # dwtools/praat_David_init.cpp (Praat 6.6.30). They have no menu entry and
  # no manual page, so Paste Commands can't record them. Their names and
  # results below come from the source and a sandbox run in 6.6.30,
  # 12 Oct 2026.

  Eigen (complex)
  # Returns: two Matrix objects, eigenvectors first, then eigenvalues; both
  #   selected afterward. ev = Eigen (complex) stops with "Multiple objects
  #   selected. Cannot assign object IDs to numeric variable". Capture both
  #   with selected# (COMMANDS_Universal.txt).
  # Layout, for an n x n Matrix (checked by A*v = lambda*v on a 3 x 3
  #   non-symmetric Matrix, residual below 1e-15):
  #   eigenvalues: n rows x 2 columns. Row k = (real part, imaginary part)
  #     of eigenvalue k. The rotation [[0,-1],[1,0]] gives rows (0, 1)
  #     and (0, -1).
  #   eigenvectors: n rows x 2n columns. Row k is the eigenvector of
  #     eigenvalue k. Its component j is at columns 2j-1 (real) and 2j
  #     (imaginary). A column pair is one component across eigenvectors,
  #     not one eigenvector.
  # Before a script relies on this layout for a new case, check A*v = lambda*v
  #   in the sandbox.

  To SVD
  # Returns: SVD. Hidden command: no menu entry or manual page, so Paste
  #   Commands can't record it. Works on a non-square Matrix (4 x 3 tested).

  Get sum
  # Verified: Get sum
  # It returned 5000 on a 2 x 50 Matrix of 50s, and the Matrix stays
  #   selected. Praat 6.6.30 sandbox, 22 Oct 2026. Returns undefined when any
  #   cell is undefined (23 Oct 2026).
