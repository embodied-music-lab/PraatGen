  Eigen (complex)
  # Returns: two Matrix objects, eigenvectors first, then eigenvalues; both
  #   selected afterward. ev = Eigen (complex) stops with "Multiple objects
  #   selected. Cannot assign object IDs to numeric variable". Capture both
  #   with selected# (COMMANDS_Universal.txt).
  # Layout, for an n x n Matrix (checked by A*v = lambda*v on a 3 x 3
  #   non-symmetric Matrix, residual below 1e-15):
  #   eigenvalues: n rows x 2 columns. Row k = (real part, imaginary part)
  #     of eigenvalue k. The rotation [[0,-1],[1,0]] gives rows (0, 1)
  #     and (0, -1).
  #   eigenvectors: n rows x 2n columns. Row k is the eigenvector of
  #     eigenvalue k. Its component j is at columns 2j-1 (real) and 2j
  #     (imaginary). A column pair is one component across eigenvectors,
  #     not one eigenvector.
  # Before a script relies on this layout for a new case, check A*v = lambda*v
  #   in the sandbox.

  To SVD
  # Returns: SVD. Hidden command: no menu entry or manual page, so Paste
  #   Commands can't record it. Works on a non-square Matrix (4 x 3 tested).
