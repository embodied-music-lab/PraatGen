# PraatGen brand files

The PraatGen wordmark is a selection in a Praat editor: a pink band covers Gen, the way you select a stretch of sound before you act on it.

| File | Use |
| --- | --- |
| `praatgen-wordmark.svg` | Wordmark on light backgrounds |
| `praatgen-wordmark-reverse.svg` | Wordmark on dark backgrounds (slate `#20242B`) |
| `praatgen-pg.svg` | Square mark for small sizes, favicons, and avatars |
| `praatgen-pg-reverse.svg` | Square mark on dark backgrounds |
| `praatgen-social-preview.png` | GitHub social preview, 1280 × 640 |

## Usage

- Use the files as supplied. Don't retype the wordmark, recolor the band, or move it.
- The band covers Gen and only Gen.
- Below 160 pixels wide, use the square mark.
- Keep clear space equal to the height of the G on every side.
- Every public piece carries the line "PraatGen is not affiliated with Praat."

## Colors

| Name | Hex | Use |
| --- | --- | --- |
| Ink | `#000000` | Type, boxes, tick marks |
| Paper | `#FFFFFF` | Background |
| Selection | `#F8D5DF` | The band behind Gen; highlights |
| Pitch blue | `#1E3CC8` | Signal lines, links |
| Formant red | `#C21431` | Warnings and errors |
| Graphite | `#4A4F57` | Secondary text |

Type: Instrument Sans for titles and text, JetBrains Mono for script text. The wordmark's letters are outlined, so the files need no fonts installed.
